Reading views. Each gets a left sidebar and a right "On This Page" table of
contents automatically.

## `dossier`

A deep single-entity report: hero metadata header, then free-form sections with
SWOT grids, risk registers, key facts, and citations.

## `dashboard`

A KPI-first surveillance view — metric cards, progress indicators, and status
badges in a responsive grid.

## `tabbed`

Multi-perspective content split behind Web Awesome tabs, so stakeholders switch
between views without scrolling one long page.

## `single`

A clean linear document — optimal reading width, breadcrumbs, and a metadata
strip. The default when no `layout` is set.
