Every report declares one `layout` in its frontmatter. The layout decides the
page's structure — you never hand-write layout grids or chrome.

## Choosing a layout

| Layout | Best for |
|---|---|
| `dossier` | Deep single-entity research reports |
| `dashboard` | KPI grids and operational surveillance |
| `tabbed` | Multi-perspective briefings behind tabs |
| `docs` | Reference documentation (this section) |
| `landing` | Marketing / homepage with a hero |
