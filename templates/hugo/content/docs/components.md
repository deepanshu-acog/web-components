atk-ui adds a small set of domain components on top of Web Awesome's ~70. Web
Awesome comes first — reach for `atk-*` only for a gap it doesn't fill.

## atk-ui components

| Tag | Use for |
|---|---|
| `<atk-metric>` | A value with its trend and normal range |
| `<atk-chart>` | Any ECharts visualization (bar, line, pie, …) |
| `<atk-data-table>` | Sortable / filterable data grid (AG-Grid) |
| `<atk-timeline>` | Dated, status-tracked milestones |
| `<atk-molstar>` | 3D macromolecular structure viewer |
| `<atk-mermaid>` | Flowcharts and process diagrams |
| `<atk-well-plate>` | 96 / 384-well microplate heatmaps |
| `<atk-sidenote>` | Marginalia and contextual notes |

## Web Awesome first

For buttons, inputs, tabs, cards, badges, trees, carousels, progress rings, and
40+ more — use the `wa-*` element directly. See the `webawesome` skill's
component reference before building anything by hand.
